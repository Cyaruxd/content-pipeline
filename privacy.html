Privacy Policy

Last updated: 27 October 2026

Content Pipeline is a personal tool used only by its owner, on their own computer, with their own Google account and YouTube channel. This policy explains what data it accesses and what it does with it.

Data accessed

With the account owner's permission, granted through Google sign-in, the tool uses YouTube API Services to:

  • upload videos and their titles, descriptions, tags and publish settings to the owner's channel (youtube.upload);
  • read the owner's channel and list of uploaded videos (youtube.readonly);
  • read analytics reports for the owner's videos, such as views and audience retention (yt-analytics.readonly).

How data is used and stored

  • Data is used only to publish the owner's videos and to produce performance reports for the owner.
  • The sign-in token and all reports are stored only on the owner's own computer. Nothing is sent to any server other than Google's.
  • No data is sold, shared with third parties, used for advertising, or used to train AI models.
  • The tool does not access data from any other user or channel.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

By using this tool you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Removing access and data

Access can be revoked at any time from Google Account → Third-party connections. Deleting the tool's local folder removes all stored tokens and reports.

Contact

Questions about this policy can be raised as an issue on this site's GitHub repository.
